Por que repetir código à mão se o computador pode repetir por você?

Hoje vamos aprender o loop for: a ferramenta que permite executar a mesma tarefa várias vezes sem copiar e colar código. Vamos percorrer listas, gerar sequências de números e no final construir tabelas de multiplicação juntos.

Aula 1

Sintaxe e uso básico do for

Imagine que você precisa escrever "Olá!" cinco vezes. Você poderia repetir a linha cinco vezes... ou usar um loop. O loop for repete um bloco de código uma vez para cada item de uma sequência.

A anatomia de um for

  • for a palavra-chave que inicia o loop
  • variável guarda o item atual da vez
  • in conecta a variável à sequência
  • sequência o conjunto que será percorrido
  • bloco indentado o que será repetido

Atenção à indentação!

Em Python, o espaço no início da linha (a indentação) indica o que está "dentro" do loop. Sem ela, o Python não entende o seu código e mostra um erro.

exemplo_01.py 
for i in range(5):
    print("Olá! Esta é a repetição número", i)
$ python exemplo_01.py
Olá! Esta é a repetição número 0
Olá! Esta é a repetição número 1
Olá! Esta é a repetição número 2
Olá! Esta é a repetição número 3
Olá! Esta é a repetição número 4

💡 Repare: o Python começa a contar do 0, não do 1!

Aula 2

Iteração sobre coleções

O for não serve só para contar números. Ele consegue percorrer coleções: listas de nomes, itens de compras, letras de uma palavra... A cada volta, a variável recebe o próximo item.

frutas.py 
frutas = ["maçã", "banana", "uva"]

for fruta in frutas:
    print("Eu gosto de", fruta)
$ python frutas.py
Eu gosto de maçã
Eu gosto de banana
Eu gosto de uva
letras.py 
for letra in "Python":
    print(letra)
$ python letras.py
P
y
t
h
o
n

💡 Até um texto (string) é uma coleção — de letras!

Aula 3

A função range() e o passo variável

A função range() cria sequências de números automaticamente. Ela aceita até três informações: início, fim (não incluído!) e passo (de quanto em quanto).

range(5) → 0, 1, 2, 3, 4
range(2, 6) → 2, 3, 4, 5
range(0, 10, 2) → 0, 2, 4, 6, 8
range(10, 0, -1) → 10, 9, 8 ... 1
contagem_regressiva.py 
for n in range(5, 0, -1):
    print(n)
print("Foguete lançado! 🚀")
$ python contagem_regressiva.py
5
4
3
2
1
Foguete lançado! 🚀

💡 O passo negativo (-1) faz o loop contar de trás para frente.

Aula 4 · Desafio

Tabelas de multiplicação

Agora juntamos tudo! Vamos criar uma tabuada usando o for. Escolha um número e veja o loop gerar a tabela inteira. Depois, vamos ver o código que faz isso acontecer.

tabuada.py 
numero = 7

for i in range(1, 11):
    resultado = numero * i
    print(numero, "x", i, "=", resultado)
$ python tabuada.py
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
